# ASD Genetic Architecture Interactive Visualization

**[Live Demo](https://pwy02221-dev.github.io/asd-genetic-architecture/)**

ASD(자폐 스펙트럼 장애)의 유전 아키텍처를 인터랙티브하게 시각화한 단일 페이지 웹 애플리케이션.

146편의 연구 논문을 종합하여 변이 유형별 기여도, 발견 타임라인, 유전자 네트워크, 성별 차이, 기술 해상도 진화를 다룸.

Built with Plotly.js. Data sourced from the LLM Wiki project.
